Help
Overview:
  Finds all nodes ending with Mirror_Grp and creates matching mirror groups on the opposite side.

How It Works:
  1. Searches the scene for any node ending with Mirror_Grp (e.g. R_Antenna_A_Ctrl_Offset_GrpMirror_Grp).
  2. Strips the Mirror_Grp suffix to get the base name (R_Antenna_A_Ctrl_Offset_Grp).
  3. Swaps the R_ prefix to L_ (or vice versa) to find the opposite-side node.
  4. Creates a new group (L_Antenna_A_Ctrl_Offset_GrpMirror_Grp) at the origin.
  5. Inserts it above the opposite-side node so it becomes a child of the new group.

Fields:
- RunAfterBuild: Check True to defer execution until after the full build finishes (recommended if the Mirror_Grp nodes are generated by later blocks).

Tips:
- Build this block after all mirrored rig components are in place.
- The new mirror groups are created with identity transforms (at origin).
